# UI Guidelines

## Appearance Mode

- ライト、ダーク、およびシステムの各モードに対応し、ユーザーが設定から選択できるようにしてください。

### Color Palette

#### Light Mode
- **背景:** 白 (#FFFFFF)
- **文字:** #4e454a
- **強調（テキスト）:** 黒 (#000000)

#### Dark Mode
- **背景:** 黒 (#000000)
- **文字:** #bab1b6
- **強調（テキスト）:** 白 (#FFFFFF)

### Design Principles
- **アクセントカラーと装飾:** 特別な意味がある場合を除き、ライトモードとダークモードで**色相と彩度を維持しつつ、明度を反転**させるものとします。
- システムカラーを優先
- ネイティブUIコンポーネントを優先（セレクト・時刻入力・スクロールバー等がテーマに追従するよう、テーマに合わせて CSS の `color-scheme` を設定する）

## Iconography & Symbols (No Unicode Emoji)

UIパーツ（ボタン、ラベル、装飾等）において、Unicodeの絵文字を使用することを原則禁止します。商用利用におけるライセンスの透明性と、各プラットフォームにおける最高のユーザー体験（アクセシビリティ・保守性）を優先してください。

- **For iOS / macOS (Swift/SwiftUI):**
  - **SF Symbols を絶対優先とする**（`Image(systemName: "...")`）。
  - ブランドロゴ等も可能な限り SF Symbols 内のものを探して使用する。

- **For Web / Chrome Extensions:**
  - **Google Material Symbols**: 標準UIアイコンの第一選択。
  - **Font Awesome (Brands)**: GitHub、X、Google などのブランドロゴが必要な場合に使用。
  - **Lucide Icons**: よりモダンでクリーンなデザインが必要な場合の選択肢（MIT License）。
  - **SVG**: 上記に存在しない固有のロゴやアセットが必要な場合のみ、コードに直接埋め込むかアセットとして管理する。

## Chrome Extension Header

`chrome-*` 拡張のポップアップと設定ページ（サイドバー）のヘッダーは、共通の見た目・構造にそろえる。詳細は `chrome-closed-template` の `docs/popup-spec.md` を正とする。

- タイトル（表示名）と説明（短い英語のタグライン）は、**英語の固定文字列でローカライズしない**。ポップアップと設定ページで同じ文言にする。
- ヘッダー右側のアイコンボタン（設定の歯車等）は共通の `.header-icon-btn` を使い、拡張ごとにサイズ・色・フォントを変えない。
- 設定を設定ページに持つポップアップには、ヘッダー右端に設定の歯車（`settings`）を置く。

## Exceptions

上記の原則に対する例外。ここに書いたもの以外は原則どおりとする。

- **言語選択のボタンに付ける国旗（Unicode 絵文字）:** Google Material Symbols に国別の国旗がないため、言語名の前に国旗を付けてよい。
  国旗は「その言語の発祥国」で選ぶ（日本語 🇯🇵、英語 🇬🇧、中国語 🇨🇳、ヒンディー語 🇮🇳、スペイン語 🇪🇸、フランス語 🇫🇷、ポルトガル語 🇵🇹）。
  ロケール識別子・表示名には国・地域を付けない方針（`LOCALIZATION_POLICY.md`）は変わらない。国旗は言語選択のボタン以外の UI パーツには使わない。
- **テーマ選択ボタンのプレビュー色:** ライト／ダークのボタンは、現在のテーマに関係なく選択後の見た目を示す固定色にしてよい。
  ライトは背景 `#FFFFFF`・文字 `#4e454a`、ダークは背景にチャコール（`#2b2b2d`）・文字に既定の文字色 `#4e454a` の明度を反転した `#bab1b6` を使う
  （ページ全体のダーク背景は黒 `#000000` のまま）。
- **他サイトに注入する UI（content script）のアイコン:** アイコンフォントを読み込めないため、Google Material Symbols の公式 SVG のパスを
  インライン SVG として埋め込む（`fill="currentColor"` で周囲の文字色に追従させる）。絵文字では代用しない。
